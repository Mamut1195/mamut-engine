Grado medio de consolidación de una capa homogénea con drenaje doble \cite{terzaghi}: $U(T_v)=1-\sum_{m\ge0}\frac{2}{M^2}e^{-M^2T_v}$, $M=\tfrac{\pi}{2}(2m+1)$, truncada a 200 términos (error $<10^{-12}$ para $T_v\ge0{,}005$). Los siete casos multicapa de GEO-006 usan la serie propia de \texttt{ORACULOS.md}; aquí se muestra la curva de la capa homogénea.
