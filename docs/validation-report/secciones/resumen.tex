\chapter*{Resumen ejecutivo}\addcontentsline{toc}{chapter}{Resumen ejecutivo}
Este informe documenta la verificación y validación de la versión~1 de MAMUT Engine, un motor de análisis estructural y geotécnico. Cada capacidad declarada para la V1 se contrasta con soluciones analíticas cerradas, derivadas por el equipo, y con resultados publicados en la literatura técnica. En los casos indicados, además, se compara con un modelo independiente en OpenSees, que se usa solo como programa de referencia de terceros.
Las tolerancias se fijan antes de ejecutar cada caso, y todos los datos de tablas y gráficos se leen de archivos versionados mediante un módulo Lua. Así el informe se puede reproducir por completo a partir del commit del Engine indicado en la portada.
